# Commercial Licensing for fSnippetCli

Most people never need this page. fSnippetCli's source code is Apache-2.0, and official
builds are free for personal use, education, non-profits, open-source projects and
organizations up to 250 concurrent copies.

## When you need a commercial license

| Situation                                                                                                                                     | Why                      |
| :-------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------- |
| More than 250 concurrent copies of **official builds** within one organization (including affiliates; VMs, containers and CI runners count) | DISTRIBUTION-TERMS.md §4 |
| Reselling official builds, or bundling / integrating them in a paid product, service or consulting deliverable                                | DISTRIBUTION-TERMS.md §4 |
| Offering fSnippetCli to third parties as a hosted / managed service                                                                           | DISTRIBUTION-TERMS.md §4 |
| Removing, hiding, altering or circumventing any notice in an official build                                                                   | DISTRIBUTION-TERMS.md §4 |
| Generated output **without** the "Powered by finfra.kr" attribution (theme-based tools only)                                                  | theme/LICENSE.md §4      |
| Using the fSnippetCli name or logo on your own product or service                                                                             | TRADEMARK.md             |

Building from source and using your own builds is **never** subject to these terms.
Official builds are provided as an integrated package that includes Finfra-proprietary
build components in addition to the Apache-licensed code, which is why that package
carries its own terms (DISTRIBUTION-TERMS.md §1–§2).

## What you get

* A perpetual license for the agreed number of copies (or attribution-free output),
  covering all versions released during the support period.
* Priority handling of bug reports.
* An invoice your procurement department will accept.

## Pricing

Pricing is per organization and scales with the number of copies. Send us the
approximate number of installs (or the intended use) and we will reply with a quote.
